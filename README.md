# THE NIGHT THAT WON'T END

**SCENARIO 10: The Looping Street**

An interactive cyberpunk visual novel game inspired by Cyberpunk 2077 and Initial D.

## Play the Game

Open `index.html` in your web browser to start playing.

## Features

- Cyberpunk 2077 visual novel aesthetic
- Neon-soaked, rain-drenched atmosphere
- 3 branching choices leading to 3 unique endings
- Dynamic background images that change with your choices
- Visual effects: chromatic aberration, scanlines, lens flares, glitch animations
- Fully interactive story with restart functionality

## The Story

You find yourself in a neon city stuck in a time loop. Cars repeat the same routes, pedestrians move like corrupted holograms, and everything is motion-blurred except you.

Make your choice:
- **A) Talk to a repeating person** → Ending: Fade Out
- **B) Spray graffiti on a wall** → Ending: Return Changed
- **C) Drive straight into the blur** → Ending: Drive Into Void

## Technology

Pure HTML, CSS, and JavaScript with no external dependencies. Uses the existing cyberpunk images in the repository to create an immersive visual experience.
